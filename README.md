# NLP Portfolio

Static site styled as a spiral notebook: on desktop, each scroll turns one page up over the binding, and the desk around it moves with floating doodles (phones and reduced-motion get plain stacked pages). Three tabs: stars (the landing page, a short intro), project, and learnings (Common Author). Each tab has its own tile border and desk doodles. The project tab holds the writeup for **Fisher**, explainable offline detection of scam and phishing messages in Indian languages ([source](https://github.com/m-rithik/Phishing-in-indian-language)).

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server
```
