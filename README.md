# NLP Portfolio

Static site with three tabs: Stars, Project, Learnings. Only the Project tab has content so far: the writeup for **Fisher**, explainable offline detection of scam and phishing messages in Indian languages ([source](https://github.com/m-rithik/Phishing-in-indian-language)).

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server
```
